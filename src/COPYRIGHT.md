# Attribution and Citation Policy

If you use **any portion** of this repository—including, but not limited to, the source code, algorithms, mathematical models, control architecture, software modules, documentation, figures, PCB designs, simulation framework, or any derivative work—for academic, research, educational, industrial, commercial, or personal purposes, **you must provide appropriate attribution to the original author**.

Appropriate attribution should include:

* The author's name (**Sambhav**).
* A reference or hyperlink to the original GitHub repository.
* A clear acknowledgment that the work is based on or derived from this project.

An example acknowledgment is shown below:

> This work is based on the *VTOL Flight Control System* developed by **Sambhav**. The original project is available at: **[https://github.com/A-sambhav/VTOL_sim]**

If this repository contributes to:
